# Tools — design stage

Planned Python tools:
- `search.py`: call Tavily search API.
- `extract.py`: retrieve and normalize facts from source pages.
- `validate.py`: check links, required fields, duplicates and hard constraints.
- `render.py`: render Persian RTL HTML using Jinja2.

These modules are **planned**, not implemented. API keys belong in local environment variables; do not commit a populated `.env`.
